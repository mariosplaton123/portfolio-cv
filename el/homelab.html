Self-hosted Home Lab

Πρακτικό έργο υποδομών πληροφορικής

Συντηρώ προσωπικό home lab με Proxmox VE για εξάσκηση στην εικονικοποίηση, τη διαχείριση υπηρεσιών, την αποθήκευση και τα δίκτυα. Η παρουσίαση βασίζεται στις τεχνολογίες του βιογραφικού μου χωρίς να αποκαλύπτει ιδιωτικές πληροφορίες υποδομής.

01 / Τεχνολογίες

Υπηρεσίες και λειτουργίες

Proxmox VE

Πλατφόρμα εικονικοποίησης για τη διαχείριση προσωπικού server και εικονικών μηχανών.

TrueNAS

Υπηρεσία δικτυακής αποθήκευσης (NAS).

Pi-hole

Φιλτράρισμα DNS για συσκευές του τοπικού δικτύου.

Uptime Kuma

Παρακολούθηση διαθεσιμότητας self-hosted υπηρεσιών.

Matrix / Synapse + Element

Self-hosted υπηρεσία και εφαρμογή ανταλλαγής μηνυμάτων.

Cloudflare Tunnel

Απομακρυσμένη πρόσβαση στην υπηρεσία μηνυμάτων.

02 / ΑΡΧΙΤΕΚΤΟΝΙΚΗ

Εννοιολογική επισκόπηση υπηρεσιών

Proxmox VE Διακομιστής εικονικοποίησης
TrueNAS Αποθήκευση
Pi-hole Φιλτράρισμα DNS
Uptime Kuma Παρακολούθηση
Matrix / Synapse Μηνύματα + Element
Cloudflare Tunnel Απομακρυσμένη πρόσβαση στα μηνύματα

Το διάγραμμα ομαδοποιεί τεχνολογίες ανά ρόλο και δεν αναπαριστά ακριβή τοπολογία VM, containers, δικτύου ή firewall.

03 / ΠΡΑΚΤΙΚΕΣ ΔΕΞΙΟΤΗΤΕΣ

Τι δείχνει αυτό το έργο

Πρακτική εξοικείωση με εικονικοποίηση, ρύθμιση υπηρεσιών, DNS, αποθήκευση, monitoring και εργαλεία απομακρυσμένης πρόσβασης. Το home lab συμπληρώνει την επαγγελματική μου εμπειρία στο IT Helpdesk 1ου/2ου επιπέδου.

Για λόγους ιδιωτικότητας και ασφάλειας δεν δημοσιεύονται εσωτερικές διευθύνσεις, hostnames, κωδικοί ή λεπτομερείς κανόνες firewall.
